# xiaoZhiMcp

## 1. 文档目的

本文档用于指导你在当前项目中使用 MCP 管理页面完成以下操作：

- 新增外部 MCP 连接并保存到数据库
- 测试连接连通性
- 加载工具列表并执行工具调用
- 删除无效的外部 MCP 连接

页面入口：`/mcp-admin.html`

***

## 2. 页面结构说明

页面分为三个区域：

1. **新增连接**

- 配置并保存外部 MCP 连接

1. **数据库连接列表**

- 查看已保存连接
- 对单条连接执行“测试”或“删除”

1. **工具调用测试（真实执行）**

- 选择目标（LOCAL 或 SAVED）
- 加载工具
- 填写动态参数并调用
- 查看调用结果 JSON

***

## 3. 快速开始

### 第一步：新增外部连接

在“新增连接”中填写：

- 连接名称（唯一）
- 是否启用
- 传输协议（`SSE` 或 `STREAMABLE`）
- URL（必填）
- Endpoint（可选）
- Headers(JSON，可选)

点击：

- `测试连通性`：仅测试，不保存
- `保存到数据库`：保存并自动刷新运行中 MCP 客户端

### 第二步：查看/管理连接

在“数据库连接列表”中可进行：

- `测试`：测试该连接是否可用
- `删除`：删除该连接并自动刷新运行中 MCP 客户端

### 第三步：调用工具

在“工具调用测试（真实执行）”中：

1. 选择目标类型：

- `LOCAL`：调用本地 MCP
- `SAVED`：调用数据库中已保存连接

1. 若为 `SAVED`，选择“连接 ID”下拉框
2. 点击 `加载工具列表`
3. 在“工具名”下拉框选择工具
4. 根据动态生成的参数输入区域填写参数
5. 点击 `调用工具`
6. 在“调用结果 JSON”查看调用结果

***

## 4. 参数填写规则

工具参数由系统根据工具 schema 动态生成，规则如下：

- 字段名优先显示中文描述：`描述（参数名）`
  - 例如：`记录内容（message）`
- 必填项会标记 `（必填）`
- 参数类型与输入控件对应：
  - `string` -> 文本框
  - `number` / `integer` -> 数字框
  - `boolean` -> 下拉框（`true` / `false`）
  - `array` / `object` -> JSON 文本框
- 若工具无参数，页面提示“当前工具无参数，将自动提交 {}”

***

## 5. 常见问题

### Q1：为什么 LOCAL 看不到外部连接的工具？

这是预期行为。`LOCAL` 模式只显示本地工具，不混入外部 MCP 工具。

### Q2：提示“连接名称已存在”怎么办？

连接名称必须唯一，请更换新的连接名称后再保存。

### Q3：提示 URL 不能为空怎么办？

URL 为必填项，请检查“新增连接”中的 URL 输入。

### Q4：调用失败怎么排查？

优先检查：

- 连接是否可连通（先点“测试连通性”）
- 目标类型和连接 ID 是否选对
- 必填参数是否填写
- JSON 参数格式是否正确（数组/对象参数）

***

## 6. 推荐使用流程

1. 新增连接后先“测试连通性”
2. 保存连接
3. 在工具调用区域切到 SAVED 并选择连接
4. 加载工具，选择目标工具
5. 填写参数并调用
6. 查看“调用结果 JSON”确认结果
